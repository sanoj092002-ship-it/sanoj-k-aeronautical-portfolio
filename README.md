# Sanoj K — Portfolio

A responsive single-page portfolio inspired by the visual language and section flow of [Polished](https://polished.framer.media/): dark canvas, floating navigation, a cursor-reactive engineering grid and flow-field behind the introduction, soft blue lighting, editorial type, a continuously moving horizontal project gallery with hover image reveal, reveal motion, horizontal experience carousel, FAQ accordions, and a contact section.

## Preview

Open `index.html` directly or serve this folder over HTTP. To serve it from this folder, run:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`. Google Fonts use a public CDN. The Military Cockpit Design case study follows the workflow from SolidWorks design through SpaceClaim geometry preparation and ANSYS meshing to CFD analysis. The Foldable-Wing VTOL case study presents XFLR5 aerodynamic and CG work, MATLAB pitching-moment plots, and the final SolidWorks model. The gas-turbine project includes the supplied blade-analysis image, the robotic-hand publication includes its demonstration video, and the crop-management publication includes the supplied article page.
